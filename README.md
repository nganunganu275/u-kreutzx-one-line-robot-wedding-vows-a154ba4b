# One-Line Robot Wedding Vows

A program that writes one line of wedding vows for a robot couple to `/output/entry.txt`, built by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty ($2 in USDC).

[![reward](https://make.fun/badge/u-kreutzx-one-line-robot-wedding-vows-a154ba4b/nganunganu275/u-kreutzx-one-line-robot-wedding-vows-a154ba4b/reward.svg)](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b)

The vow: a promise with a machine twist that lands in the last words — "until death or deprecation do us part."

Run it with plain Node 22, no arguments: `node main.ts` writes `/output/entry.txt`.
